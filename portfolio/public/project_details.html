Mobile Food Ordering App

โมบายแอปพลิเคชันสั่งอาหารและบริการส่งอาหารในชุมชน

ที่มาและความสำคัญ

โครงการนี้ถูกพัฒนาขึ้นเพื่อช่วยให้ร้านค้าชุมชนสามารถขายอาหารออนไลน์ได้ง่ายขึ้น โดยใช้แอปพลิเคชันที่ใช้งานสะดวกและรองรับการสั่งซื้อผ่านมือถือ

วัตถุประสงค์

  • พัฒนาแอปพลิเคชันสั่งอาหารที่ช่วยให้ร้านค้าชุมชนเข้าถึงตลาดออนไลน์
  • ใช้ Flutter framework และภาษา Dart ในการพัฒนา
  • รวมระบบแจ้งเตือนแบบ Push Notification ผ่าน Firebase
  • รองรับการแสดงตำแหน่งร้านค้าผ่าน Google Maps

คุณสมบัติของแอปพลิเคชัน

  • สมัครสมาชิกและเข้าสู่ระบบ
  • บันทึกคำสั่งซื้อและแสดงคิวของลูกค้า
  • เลือกร้านค้าและสั่งอาหารผ่านแอป
  • รองรับการชำระเงินผ่าน QR Code หรือเก็บเงินปลายทาง
  • ผู้ส่งสามารถรับและติดตามออเดอร์ได้

เทคโนโลยีที่ใช้

  • Flutter (Dart) - พัฒนาโมบายแอป
  • Firebase - จัดเก็บข้อมูลและระบบแจ้งเตือน
  • Google Maps API - แสดงตำแหน่งร้านค้าและระบบนำทาง

พัฒนาโดยนักศึกษา: นางสาวสุภรินทร์ ศรีคล้อย และ นายธนพล ไตรธนสมบัติ
